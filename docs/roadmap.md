# Roadmap

Honest list of what is not there yet.

- Word-aligned captions (faster-whisper on the generated narration) instead of proportional timing.
- More hosts: pose set (pray, walk, hold a sign), outfits, a second character.
- Scene transitions beyond the dip to background; a wipe/slide set.
- Royalty-free music helper with license tracking.
- Background removal and slide-in cutouts for user photos.
- Voice cloning is out of scope.

Good first issues: a new `backdrop` theme, a new `pose` in `templates/story.js`, a narration language default voice, a docs example.
