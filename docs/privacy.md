# Privacy

Videomaker has no server and no telemetry. Narration, rendering, captions and transcription run on your machine. The only network traffic is what you start: `videomaker setup` (GitHub releases and git clones at pinned versions) and the photos you download yourself.

Storyboards often contain real names, photos and phone numbers (it is an ad, after all). Keep those projects in your own folder, not in a public repository. The repository examples are synthetic on purpose.
